# Ninjas & Missões API

## Como rodar

```bash
git clone https://github.com/GuilhermeAizzaSano/ninjasProva.git
cd ninjasProva
./mvnw spring-boot:run
```
> No Windows PowerShell: `.\mvnw.cmd spring-boot:run`

## Testes

Importe o arquivo [`postman_collection.json`](./postman_collection.json) no Postman para executar as requisições de teste da API.
